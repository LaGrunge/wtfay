# Словари для трёхсловных адресов

Адрес = `{common, common}` (неупорядоченная пара, два разных слова) × `argo`.
Ячейка 3×3 м, вся планета: 510 072 000 км² / 9 м² ≈ 5,667 × 10¹³ ячеек.

| Файл | Слов | Что это |
|---|---|---|
| `common.txt` | 120 358 | существительные, глаголы (инфинитив), прилагательные, наречия в начальной форме |
| `argo.txt` | 10 259 | заголовочные слова «Словаря русского арго» В. С. Елистратова (2000) |
| `argo_rejected.tsv` | — | всё, что выброшено из арго, с причиной |
| `stats.json` | — | цифры последней сборки |

Комбинаций: C(120 358, 2) × 10 259 ≈ 7,43 × 10¹³, то есть в 1,31 раза больше, чем ячеек.
Для полного покрытия арго должно быть не меньше 7 825 слов.

Оба файла отсортированы и уникальны по ключу `ё → е`. Пользователь может
вводить «е» вместо «ё», поэтому сравнивать слова нужно по этому ключу. Списки
между собой не пересекаются.

## Источники

- `common`: [danakt/russian-words](https://github.com/danakt/russian-words) (1,5 млн словоформ)
  и AOT из [laboratory50/russian-spellpack](https://github.com/laboratory50/russian-spellpack) (LGPL).
  Начальные формы и части речи определялись через pymorphy3 (OpenCorpora).
  Сверка с OCR «Русского орфографического словаря» РАН (около 200 тыс. слов) почти
  ничего нового не добавила, но подтвердила слова.
- `argo`: OCR (tesseract, rus) скана DjVu, 696 страниц.

## Правила чистки

`common`:
- только кириллица без дефиса, длина от 3 до 15;
- без имён, фамилий, отчеств, топонимов, аббревиатур и организаций;
- без матерных корней (мат только в третьем слове);
- без слов, которые есть в арго.

`argo`:
- склейка переносов строк;
- все заголовки статьи (`ЖИДЯКА, -и, ЖИДЯРА, -ы…`);
- исправление ударений, прочитанных как буквы (`ильйч → ильич`, `-ёть → -еть`, `её → е`, `-ты → -ть`);
- выброшены косвенные формы, служебные слова, обычные слова, встречавшиеся только
  внутри фраз со «см.», слипшиеся фразы (`распахнутьварежку`) и мусор OCR.
  Заголовок с грамматической пометой (`ЛИМИТА, -ы, ж.`) считается словарной формой,
  даже если pymorphy с этим не согласен.

Скрипты сборки лежат в `scripts/`.
