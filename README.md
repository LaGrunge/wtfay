# wtfay

Русский клон what3words для своих: любая точка Земли с точностью до квадрата 3×3 м
получает адрес из трёх слов. Первые два — обычные слова, третье — арго из «Словаря
русского арго» В. С. Елистратова.

```
Москва, Красная площадь   гистаминаза запуганный кот
```

- `core/`: алгоритм на Kotlin без зависимостей (сетка, словари, кодирование), консоль и тесты.
- `data/final/`: итоговые словари и описание того, как они собраны.

## Консоль

```sh
cd core
gradle test
gradle run                                          # демо: 30 мест СНГ
gradle run --args="encode 55.75393 37.62079"
gradle run --args="decode гистаминаза запуганный кот"
```

## Как это устроено

- **Сетка.** Шар режется на полосы по широте высотой 3 м. В каждой полосе столько ячеек
  шириной не меньше 3 м, сколько помещается по её длине. Всего 5,667 × 10¹³ ячеек.
- **Адрес.** Неупорядоченная пара из `common.txt` (120 358 слов) × слово из `argo.txt`
  (10 259 слов) даёт 7,43 × 10¹³ адресов, это в 1,31 раза больше, чем ячеек. Номер
  ячейки перемешивается перестановкой на сети Фейстеля с фиксированным `Codec.SEED`,
  поэтому у соседних ячеек непохожие адреса.
- **Ввод.** Порядок первых двух слов, регистр и ё/е не важны.

Любое изменение словарей меняет все адреса, поэтому словари нужно версионировать.
